
# Laundry Mart Login Page

## Description
A split-screen login page built using HTML and CSS Flexbox.

## Features
- Two-column layout
- Laundry image on the left
- Email and password inputs
- Forgot Password link
- Login button
- Register Now link
- Responsive styling
- Input validation

## Technologies
- HTML5
- CSS3
- Flexbox

## Files
- index.html
- index.css
- Readme.md

## How to Run
Open index.html in a web browser.
